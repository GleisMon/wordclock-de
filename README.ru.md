# Wortuhr — прошивка немецких часов-слов (ESP8266)

Прошивка для напечатанных часов со словами (немецкая лицевая панель 12 × 11 букв, 132 светодиода WS2812B).
Управляет ими **Lolin NodeMCU v3 (ESP8266)**, спрятанная в подставке. [Deutsch](README.md)

## Что умеет

- Настройка без программирования: Wi-Fi с телефона, время из интернета (NTP), летнее время автоматически.
- Случайные цвета: при каждой смене показаний **все** слова получают новые цвета, соседние не повторяются.
- Яркость, ночной режим, слово «MINUTEN» вкл/выкл, сердце в начале часа (по умолчанию выключено).
- Страница настроек: **http://wortuhr.local**, языки DE / RU / EN, расширенное меню отдельно.
- Обновления по Wi-Fi из GitHub Releases: проверка раз в сутки, установка кнопкой или автоматически ночью.
  Прошивка подписана, TLS проверяется по корневым сертификатам.
- Аварийный режим: 3 неудачных запуска подряд → точка доступа «Wortuhr-Rescue» со страницей загрузки прошивки.
- Лимит тока светодиодов 1.5 А под блок питания 2 А (меняется в расширенных настройках).
- Опционально экран 0.91" OLED (SSD1306 128×32, SDA → D2, SCL → D1) в подставке v5: адрес и настройка Wi-Fi,
  ошибки, прогресс обновления, по желанию точное время. Определяется сам; время показа после включения
  настраивается (по умолчанию 5 мин), потом гаснет.

## Индикация углами

| Углы пульсируют | Значение |
|---|---|
| синим | открыта точка настройки «Wortuhr-Setup» |
| оранжевым | подключение / ожидание времени |
| красным | аварийный режим |

## Первый запуск

1. Прошить по USB (micro-USB платы) файл из `build/` или из релиза.
2. Подключиться телефоном к «Wortuhr-Setup» → Configure WiFi → выбрать сеть.
3. Дальше всё по воздуху: `http://wortuhr.local`.

## Выпуск новой версии

1. Поднять `FW_VERSION` в `firmware/Wortuhr/version.h`.
2. Коммит, затем тег `vX.Y.Z` и push. GitHub Actions соберёт, подпишет и опубликует `wortuhr-de.bin` + `version.json`.
3. Часы увидят новую версию при следующей проверке (или по кнопке «Nach Update suchen»).

Приватный ключ подписи **не в репозитории**: он лежит локально (`..\_PRIVAT_schluessel\private.key`, рядом с репозиторием) и
в секрете репозитория `SIGNING_KEY`. Если его потерять, новые версии по воздуху ставить будет нельзя: придётся
один раз прошить по USB прошивку с новым публичным ключом.
